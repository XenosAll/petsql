DAU Analysis - SQL Project

Описание

В проекте рассчитывается и анализируется метрика Daily Active Users (DAU) - количество уникальных пользователей, взаимодействовавших с платформой в течение одного дня.

Цель

Рассчитать ежедневную активность пользователей которые взаимодействовали за период начиная с 1 января 2022 в течение одного дня

* ежедневное количество активных пользователей;
* максимальный DAU, достигнутый к текущему дню;
* разницу между текущим DAU и максимальным значением.

Данные

Для анализа используется таблица userentry.

Основные поля:

* user_id - идентификатор пользователя;
* entry_at - дата и время входа пользователя на платформу.

SQL-технологии

В проекте используются:
* PostgreSQL
* CTE (WITH);
* generate_series();
* DATE_TRUNC();
* COUNT(DISTINCT ...);
* LEFT JOIN;
* COALESCE();
* оконная функция MAX() OVER();
* ORDER BY;
* фильтрация данных через WHERE.
* EXTRACT
Логика решения

1. Создание календаря

С помощью generate_series() создаётся непрерывная последовательность дат, начиная с 2022-01-1.

Это позволяет учитывать дни, в которые на платформу никто не заходил.

2. Расчёт DAU

Для каждого дня рассчитывается количество уникальных пользователей:

COUNT(DISTINCT user_id)

Дата и время округляются до дня с помощью:

DATE_TRUNC('day', date)
3.  Фильтрация данных произошедшие в 2022
where EXTRACT(YEAR FROM U.ENTRY_AT) = 2022

4. Объединение данных

Календарь соединяется с рассчитанным DAU через LEFT JOIN.

Благодаря этому в результате сохраняются все даты, включая дни без активности пользователей.

5. Обработка пропущенных значений

С помощью COALESCE() значения NULL заменяются на 0.

5. Расчёт максимального DAU

Используется оконная функция:

MAX(coalece(d.dau, 0)) OVER (
   over (ORDER BY c.date_from_calendar)


Она позволяет получить максимальное значение DAU, достигнутое к каждому конкретному дню.

6. Расчёт diff_dau

Показатель рассчитывается по формуле:

diff_dau = current_dau - max_dau_cnt

Если значение равно 0, текущий DAU соответствует максимальному значению.

Отрицательное значение показывает, насколько текущая активность ниже достигнутого максимума.

Результат

Итоговый запрос возвращает четыре столбца:

Поле Описание
date_from_calendar Дата
daily_active_users_cnt Количество уникальных активных пользователей
max_dau_cnt Максимальный DAU, достигнутый к текущей дате
diff_dau Разница между текущим DAU и максимальным значением

Результат отсортирован по дате в возрастающем порядке.

Вывод

В результате был создан SQL-запрос для расчёта ежедневной пользовательской активности.

Использование календаря через generate_series() позволяет корректно учитывать дни без активности, а оконные функции позволяют анализировать изменение DAU относительно предыдущих пиков.

Полученный подход можно использовать как основу для дальнейшего анализа продуктовых метрик, например WAU, MAU, Retention и Stickiness.

# Анализ Daily Active Users (DAU)

SQL-проект по расчёту и анализу ежедневной активности пользователей.

### Что считается
- Ежедневное количество уникальных активных пользователей (DAU)
- Максимальный DAU, достигнутый к текущему дню (running maximum)
- Разница между текущим DAU и историческим максимумом

### Использованные техники
- CTE
- `generate_series` (календарь дат)
- Оконная функция `MAX() OVER`
- `DATE_TRUNC`, `LEFT JOIN`, `COALESCE`

### Логика
Сначала строится полный календарь дат, затем к нему джойнится рассчитанный DAU.  
Это позволяет учитывать дни без активности. Оконная функция показывает максимальный DAU на каждый момент времени.
